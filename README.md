# StudyClock

勉強中に机へ置いて使う、時計と学習時間記録のPWAです。ビルド不要の静的サイト(HTML/CSS/JS 1ファイル + Service Worker)で、外部通信・依存関係はありません。

## 起動
```
python3 -m http.server 8000   # → http://localhost:8000
```
(Service Workerはlocalhostまたはhttpsで動作します。)

## GitHub Pagesで公開
1. このフォルダをGitHubリポジトリの `main` にpush
2. Settings → Pages → Source を **GitHub Actions** に設定
3. `.github/workflows/pages.yml` が自動でデプロイ。URLは `https://<ユーザー名>.github.io/<リポジトリ名>/`

すべて相対パスなので、サブパス配下でもそのまま動作します。

## iPhoneでの使い方
Safariで開く → 共有 → 「ホーム画面に追加」。ホーム画面から起動するとフルスクリーンで使えます。
- 画面を消灯させたくない場合は、設定の「画面を点灯したままにする」をオンにしてください。ブラウザ側の制約で効かない場合は、iOSの「設定→画面表示と明るさ→自動ロック」を「なし」に。明るさやスリープをWebアプリから完全に制御することはできません。
- 時計画面をタップすると操作UIが隠れます。

## データ
記録・設定は `localStorage` に保存されます。ブラウザのサイトデータ消去で失われるため、設定画面の「記録を書き出す」で定期的にバックアップしてください。
タイマーは開始時刻を基準に計算するため、バックグラウンド化・再読み込み後も時間がずれません。一時停止中の時間は含まれず、日をまたぐ記録は日ごとに分割して集計されます。
